# 2026-11-05

## Vietnam Province Selection Map (Quy Nhon AI Travel)

Built a game-style, clickable province map for `#map-section`, replacing the World Route
map as the default view (flight route kept behind a segmented toggle).

**Files added**
- `js/vietnamMapData.js` (85 KB, generated) — 34 provincial units, SVG paths, label anchors,
  per-province bbox, country outline. Web Mercator, viewBox `0 0 1000 2051.5`.
- `js/vietnamRegions.js` — bilingual (vi/en) description + 4 highlights for all 34 units.
- `js/vietnamMap.js` — `VietnamMap` module: renders the SVG, pan/zoom via viewBox,
  selection, info panel, region legend, label tiering by zoom/on-screen size.
- `css/vietnam-map.css` — map card, sea canvas, panel, legend, responsive rules.
- `tools/build_map_data.py` — GADM 4.1 (63 provinces) dissolved into the 34 units of
  Resolution 202/2025/QH15, simplified, projected, greedy label placement.
- `tools/preview.mjs` — minimal CDP headless-Chrome screenshot helper (`--clip`, `--js`, `--scale`).

**Files modified**
- `index.html` — new map section markup, view switch, extra `<script>`/`<link>`.
- `js/map.js` — added `lastRoute` + `refresh()` so Leaflet recovers after being shown from `display:none`.
- `js/app.js` — added the missing `change` listener on `#app-lang-select` (the EN/VI switch was dead code).
- `js/translations.js` — new map keys; `navMap`/`mapTitle`/`mapSubtitle` retargeted.
- `PROJECT_CONTEXT.md` — feature row 13, admin-unit + data-licence notes.

**Decisions**
- 34 units (2026), not 63 — Bình Định is now part of Gia Lai with the capital at Quy Nhơn.
- GADM 4.1 geometry is free for non-commercial use only; must be replaced before commercial launch.
- Labels are placed offline by a greedy non-overlap solver, then filtered by zoom tier
  (10 / 16 / 20 / 26 / 31 / 34 depending on on-screen map width and zoom).
- Legend hides below 1180px and while zoomed.

**Known, not fixed (pre-existing)**
- `.results-wrapper { padding: 3rem 0 }` overrides `.container`'s horizontal padding, so all
  result sections go full-bleed below 1200px.
- `manifest.json` still points at `/assets/airport-icon.png` while the file is `.jpg`.
